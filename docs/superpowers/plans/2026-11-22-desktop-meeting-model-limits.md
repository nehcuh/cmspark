# 桌面会议与模型输出的实施计划

GitHub: #880，见[产品规格](../specs/desktop-meeting-model-limits.md)。

1. 在录屏模块复用 IndexedDB 顺序写入、最后一块落盘和部分录制恢复。在桌面会议采集模块获取用户所选屏幕流和可选麦克风，停止时释放全部来源。分别测试取消、缺轨、来源中断和停止落盘。
2. 在 MeetingPanel 的显式点击中打开选择器，保存本次来源范围和转写接收方，将同一音频接到录屏与现有 PCM 控制器。通过旧麦克风模式、桌面模式和中断后的逐字稿回归。
3. 在模型预算、供应商适配器、模型设置和一句话设置里共用按官方端点核实的能力，覆盖正反例、发送字段及旧配置。
4. 用 Windows 外部窗口和备好的会议录音验收。分别记录每种声音来源、首段转写、停止与恢复、视频和纪要。同步 Companion、扩展、安装器版本，运行仓库检查、独立源码评审和 PR CI。合并后核主干、三平台预演、正式标签与发行附件摘要。
