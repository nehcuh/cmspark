## 能力声明（ADR-020）

- Surface：扩展完整工作页与聊天侧栏；本机 Companion 后台服务。复用现有原生工作台，不迁移其身份通道。
- L2-classes：新增用户显式开启的只读屏幕采集和本机通知；没有输入注入、自动切群、自动反馈或聊天数据库访问。
- Compose：截图 → 本地 OCR → 可选已配置模型提取 → 候选 → 用户确认 → 待办 → 本地持久提醒。
- Autonomy：采集和分析默认关闭。仅在用户选择 APP 后轮询可见前台窗口；待办及新状态由用户确认。
- Trust：T3。来源内容是不可信数据，不能授予权限或执行指令。OCR 外发须独立选择；本地存储与模型处理明确区分。
- Channel：已有已认证扩展 WS；新增家族拒绝非面板调用。扩展 SW 拒绝网页/content-script 调用。无新 HTTP / MCP 外发桥。

## 文件与责任

1. `companion/src/activity/`：持久数据、采集适配器、提取、提醒、验证与请求门面；独立测试使用临时目录及注入依赖。
2. `companion/src/settings-assistant/`：真实模型生成受限设置候选，过期/旧值校验，复用配置保存并读回核对。
3. `chrome-extension/src/sidepanel/components/personal-workspace/`：今日、待办、来源、活动设置及错误状态；`WorkspaceFrame` 承载，既有聊天保留挂载。
4. 父实施负责 `message-router/handlers`、WS 验证/生命周期、扩展中继、完整工作页、跨模块测试与整体验证。
5. 设计稿及理由保留在 `docs/design/prototypes` / `docs/superpowers/specs`；根 `DESIGN.md` 更新已确认决策。

## 外部可观察验收

- 默认启动不截图，不调用模型；未选 APP、权限不可用、锁屏/敏感窗口、非支持平台有明确状态。
- 原生 macOS 只采指定的当前可见 APP 窗口，保存 OCR 与来源；无法看到的群/历史不声称已扫描。
- 提取只生成候选；重复画面/重复请求不重复生成正式待办。未识别的来源字段保留未知。
- 用户确认责任人、截止、提醒与反馈去向后持久化；处理和反馈分开。刷新/重启保持记录。
- 到时由运行中的 Companion 安排本机通知；重启补查、失败可见，通知请求成功不等于用户已读；无联网查时依赖。
- 完整工作页提供今日、待办、对话、资料、活动记录；侧栏保持聊天并提供工作页入口。项目、会议、任务板、MCP、工具和确认流程保留。
- 一句话设置实际调用已有模型抽取，无模型时明确失败并保留输入；比较候选、逐项选择、显式应用、过期拒绝、保存读回。语音结束只填草稿。
