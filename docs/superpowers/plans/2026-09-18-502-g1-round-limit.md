# 502-D-G1 round_limit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.
>
> GitHub: #502 · Spec §5.3 G1 · Pi `out-pi.md`
> Blast: **T2**（Autonomy 文案 + 续跑接线；不引入完整 goal 对象）

**Goal:** `MAX_TOOL_CALL_ROUNDS=100` 触顶从「假死：loop 仍 active 却不续跑、UI 还写推进中」变成「这一段结束；已武装则排下一段，未武装则建议卡」。连续失败 / 同工具空转仍是 `circuit_breaker`，不自动续。

**Architecture:** 把 100 轮从 `RunTerminal="circuit_breaker"` 拆出 `"round_limit"`。`onLoopRunFinished` 对 `round_limit` **不 return**，走与正常 run 结束相同的 enqueue / suggest 路径。Adapter 100 轮出口改 `chat.done`（或带 `finish_reason:"round_limit"`），**禁止**再发「达到最大工具调用轮次 (100)，已暂停。」

**Tech Stack:** companion TypeScript · `companion/tests/loop-kernel.test.ts` · adapter 现有 chatCreate

**NEVER:** 删 100；把 same-tool / 5-failure 也改成自动续；cruise 跳过 L2；worker 线程 arm loop。

现有测试 `circuit_breaker / error terminals: no continuation` **必须继续绿**。新增：

```ts
test("round_limit: armed + unticked evidence → enqueue next run (G1)", () => {
  const tid = newThread()
  kernel.armLoop(tm, tid, "explicit_command", { audit: auditSink })
  setProgress(tid, [{ id: "live:0", text: "x", done: false }])
  exitCheck(tid, stats({ terminal: "round_limit", toolCalls: 8 }))
  assert.equal(getLoop(tid)?.status, "active")
  assert.equal(queues.peekNextRunCount(tid), 1)
  assert.equal(audits.some((e) => e.type === "task_loop.run_scheduled"), true)
  assert.equal(audits.some((e) => e.type === "task_loop.paused" && e.reason === "circuit_breaker"), false)
})

test("round_limit: not armed + tools ran → suggestion card, no enqueue", () => {
  const tid = newThread() // no armLoop
  setProgress(tid, [{ id: "live:0", text: "x", done: false }])
  exitCheck(tid, stats({ terminal: "round_limit", toolCalls: 8 }))
  assert.equal(queues.peekNextRunCount(tid), 0)
  assert.equal(suggestFrames.length, 1)
})

test("circuit_breaker still does not continue", () => {
  const tid = newThread()
  kernel.armLoop(tm, tid, "explicit_command", { audit: auditSink })
  setProgress(tid, [{ id: "live:0", text: "x", done: false }])
  exitCheck(tid, stats({ terminal: "circuit_breaker" }))
  assert.equal(queues.peekNextRunCount(tid), 0)
})
```

Kernel 改法：把

```ts
if (stats.terminal === "circuit_breaker" || stats.terminal === "error") {
  audit(... paused ...)
  return
}
```

改成 **只** 拦 `circuit_breaker` 与 `error`。`round_limit` 当作 `terminal: null` 一样往下走（仍要记账 `runs_used` / tokens）。`round_limit` 审计事件建议 `task_loop.round_limit`（新 type 可进 capability-audit；若怕协议膨胀，复用 `task_loop.run_scheduled` 并带 `reason:"round_limit"`）。
