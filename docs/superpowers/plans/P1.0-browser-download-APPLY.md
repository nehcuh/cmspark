# P1.0 browser_download — apply & verify

## Mandatory once after pull

```bash
node scripts/apply-browser-download-p10.mjs
```

This idempotently patches:

- `companion/src/server.ts` — path sandbox gate, worker path deny, longer dispatch timeout
- `chrome-extension/src/background/browser-bridge.ts` — `browser_download` case + alias + handler

`npm --prefix companion test` and `npm --prefix chrome-extension test` also run the apply script first.
