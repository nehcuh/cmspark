# 对话上下文控制

GitHub: #887

## 交互

顶栏提供「自动匹配知识」「带入当前网页」「选用知识和技能」。窄栏保留一个入口，展开后可使用全部控制。选择按 Chrome 扩展中的对话保存，重开同一对话时回显。没有对话时先创建空白对话，再设置和发送。

关闭自动匹配后，这个对话仅带入手动选择的知识。关闭网页后，扩展不会为这次请求查询当前标签页，Companion 也不会在后续工具轮次恢复自动网页上下文。显式上传、对话历史和手动使用工具遵循现有行为。

手动选取使用已登记的知识与技能，复用知识库及技能管理入口。用户可采用已有的本地文件导入、技能安装路径，选择时不发出新的下载请求。手动知识引用参与现有预算，并按明确选择标记来源。选择技能后仅列出所选技能供模型按需加载，安全规则和工具授权照常执行。

## 请求

普通消息、附件、排队和重新生成带上提交时的选择。给进行中回复补充消息时，使用正在运行的上下文。旧客户端按现有规则工作；新客户端遇到未声明支持的 Companion 时拒绝发送带有明确上下文选择的请求。
