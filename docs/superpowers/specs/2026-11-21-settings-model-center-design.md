# 设置与模型中心

GitHub: #798、#754、#876

全局设置首页按模型与服务、输入与交互、数据与知识、隐私与权限、工具与集成、连接与维护组织。原有业务入口保留，跳转到具体项目。窄栏进入二级页面并可返回，保留草稿。首页可搜索或描述配置目标，连接异常提供配对入口。

模型与服务按用途展示当前选项、能力、发送内容和更改入口，覆盖对话、看图、听写纠错、聊天听写、会议转写、纪要、活动提取和后台任务。已配置文本模型可保存为有名称的配置并引用，存量主模型和视觉链路继续读现有配置。本机资源仍保留独立下载许可。显示模型和端点时隐藏密钥，协议和兼容选项放在服务表单。更改继承的默认值前列出受影响的用途。

会议纪要可继承默认模型，也可使用已配置的独立文本模型。换纪要模型只影响新生成。生成时核对实际目标和本次输入。外部会议 ASR 属于独立配置，默认本机。首个外部转写路径处理导入的音频，用户明确同意所选音频和目标，配置变化使确认失效。聊天配置、会议录音及录屏采集均保持各自原确认和数据边界。

一句话入口共用稳定设置标识、受控值、作用域和保存回执。查找和确切的低风险配置支持本地路径。目标含糊时说明需要的选择。纯查询可离线。AI 仅生成受验证的候选。仅用户确认的操作可以写入现有配置接口，保存前检查冲突，保存后读回。已有登录、配对、密钥、安装、权限和数据外发流程继续作为独立操作。

验收包括旧配置升级、窄栏可访问性、未配模型、配置并发变化、模型切换作用域、独立纪要模型、会议音频授权边界、成功段保留及服务错误。逐项核本地、PR、主线、同树发布预演和正式安装包证据。
