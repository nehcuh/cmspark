# Mini 资料搜索

在已配对的小窗提交关键词，一次检索知识库标题、描述、标签、正文，以及历史对话中已保存的用户发言和助手回复。正文按字面匹配，英文字母忽略大小写。搜索使用本机现有的资料和对话存储。

每份匹配的资料和每条匹配的消息各占一条结果。列表交替显示两类来源，按页继续加载。点击对话片段时，用会话 ID 和消息 ID 重新读取当前消息，在小窗内高亮并定位关键词。点击长文深处的匹配也能看到对应上下文。打开时若原文已不可用，界面提示重新搜索。归档对话可查，回收站、后台工作线程、系统消息和工具输出不参与检索。

验收覆盖仅在知识正文或对话消息出现的关键词、长文本截断点之后的命中、跨页定位和打开前删除的消息。公开发布的夹具使用合成内容。
