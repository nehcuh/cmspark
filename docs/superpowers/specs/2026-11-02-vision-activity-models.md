# 视觉协议与聊天待办图像抽取

GitHub: #822 · 关联 #752 · T3

## 用户行为与验收

视觉设置支持 OpenAI / Anthropic，并可显式复用主模型协议、鉴权与允许的请求头。未配置协议的旧视觉设置仍走 OpenAI。复用时保留用户已有专用视觉 Key；主 Key 只按既有占位继承规则在 Companion 内解析。

工作中心保留 OCR 文本 → 主模型模式；新增复用视觉、专用图像模型、本机 Qwen 三种模式。模式选择与专用 URL / model / protocol / key 在原隐私设置内完成。公开状态只展示密钥是否已配置。图片处理需单独授权；授权绑定具体模式、端点、模型、鉴权配置或本机权重身份。复用的全局模型配置变更后须重新授权；保存授权须校验表单展示时的目标标识，旧表单不能替新端点授权。关闭图片授权后无图片推理请求。

已授权图片模式下，导入截图后直接抽取候选，不依赖本机 OCR 成功；自动采集也走所选模式。本机 OCR 在原模式中保留原行为。图像模型一次返回 transcript 与 candidates，候选引用必须存在于此次转录；保存转录后才能接纳候选。模型输出是待核对数据，仍需用户确认正式事项，不自动创建提醒或发送消息。

Qwen 复用权重校验、Python 环境、加载与 worker 协议，新增 analyze 请求；定位接口保持既有契约。只使用已下载权重，不自动下载或启用电脑控制。本机抽取不调用主模型或视觉云端，无云端回退。取消/设置变更/停止后终止图像请求，结果不入库；本机请求结束释放 worker。

## 能力声明

Surface: 辅助视觉设置、工作中心、activity 与本机 Qwen worker。
L2-classes: 保持采集与定位门；无新增电脑操作。
Compose: 截图 → 所选模型 → 转录与候选 → 原文核对 → 用户确认。
Autonomy: 已启用采集与已授权处理；正式任务仍需确认。
Trust: 图片/转录/模型输出均为不可信数据；专用凭据仅后台持有。
Channel: 显式所选端点或本机推理；无自动云端回退。

## 验证与放行

验证 OpenAI/Anthropic 真实请求结构、复用/密钥保持、不同提示词缓存隔离、图片授权及目标变更、专用凭据遮蔽、本机无云端调用、导入直接抽取、来源证据接纳、取消、旧 OCR 行为与定位回归。运行 Companion/扩展相关测试及构建，实际渲染控件验证操作及窄屏。机器通过后独立对抗 → Pi 复审；不修改 live config.json，不自动下载模型。
