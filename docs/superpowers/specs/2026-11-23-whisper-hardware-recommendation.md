# 本机语音识别硬件适配

GitHub: #884

推荐依据本机可获取的内存、平台、CPU 与已验证的运行后端，明确区分硬件识别和实际加速可用性。推荐是建议，不改动已保存的引擎与模型，模型和运行组件仍由用户主动下载；检测失败时说明未知，提供现有模型选择。速度与精度是取舍，不能仅以内存大小承诺实时性能。

Apple Silicon 上先验证安装包真实携带 Metal 后端及其依赖，再允许该后端运行；后端加载或推理失败需保留可用的 CPU 路径，其他平台按其实际支持的运行方式工作。任何动态组件必须随既有签名、完整性及跨平台打包校验交付，不得依赖用户预装 Homebrew。

性能验收以相同模型、音频、二进制和机器比较，并分别记录冷启动、模型已加载或缓存热的识别耗时、从录音结束到文字出现的端到端延迟与识别内容；不能用静音或首次/后续混合的时间承诺速度。若需要常驻服务，必须在实际分发环境验证进程生命周期、隔离、取消、退出与故障恢复，不能只依赖开发机上的外部服务。

覆盖用户显式下载、已有配置不被覆盖、未知硬件、各推荐档与不支持/失败回退；在 Apple Silicon 无 Homebrew 的实际安装包上验证 Metal 和资源闭包。语音测试应包含真实人声和静音，以发现识别质量与幻觉回归。

麦克风：用户可在听写设置选择已授权可见的输入设备，或跟随 Chrome 默认；本机、系统和外部转写传递准确设备 ID，设备不可用不得悄悄改用其他麦克风。浏览器听写由 Chrome 处理，页面需明确说明。设置读取设备列表不得主动申请麦克风权限。

Windows：当前 x64 清单仅含 CPU 后端且强制 CPU；GPU 需独立准备并核验兼容后端，检测驱动及显存并以实际运行探测确认，而非把枚举设备等同于可用。NVIDIA CUDA 与跨厂商 Vulkan 均需匹配对应的构建与驱动；未验证的 ARM64 不得沿用 x64 的 GPU 承诺。
