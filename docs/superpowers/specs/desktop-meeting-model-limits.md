# 桌面会议与模型输出设置

GitHub: #880

## 会议

用户在个人工作台的会议页选择桌面会议，核对转写接收方，再通过共享选择器选定外部会议窗口或整个屏幕，并勾选共享声音。Windows、浏览器版本与所选来源决定能否共享声音。用户可以同时采集自己的麦克风，也可以明确选择只录对方。所请求的任一路声音缺失时，显示原因并允许重新选择。选择整个屏幕时应说明系统声音也可能包括其他应用。

屏幕视频只写入现有浏览器本地录屏库。音频输入混合一次，分给 WebM 和现有连续 PCM 转写管线。开始、主动停止、共享被撤销、关闭页面、存储失败各自需要释放设备，并区分完整录制和可恢复的部分。外部转写使用现有逐次音频确认。纪要沿用已保存逐字稿、接收方和文字预览。

## 模型与服务

分别展示厂商针对当前模型的单次输出上限、本地请求上限与思考强度。增加思考预算可能挤占可见回复的空间，各供应商的处理规则与可用档位取决于模型。查表须核对协议、官方地址和精确模型名，兼容网关无法核实时明确显示未知。保留旧版手动值，自动模式沿用当前上下文约束。前端展示、实际请求和一句话设置读取一致的能力定义。

## 验收

从会议页开始，分别核对录屏中可识别的外部窗口、共享来源的已知语音、麦克风分支、停止前出现的转写、持久化的录屏与逐字稿，以及基于该逐字稿生成的纪要。记录来源和设备条件。模型覆盖已知、未知、非思考模型、受限档位、用户自定义上限与实际出站请求。

- 首次取消、缺少所选音轨、撤销共享、关闭页面和写盘失败时，检查提示、停止采集、设备释放、重新选择以及不完整视频的恢复状态。主动停止要等最后一块落盘。
- 本机转写只发送到本机 Companion。外部转写确认前不得发出音频；确认后接收方仅收到所选声音的音频。视频始终留在浏览器内。生成纪要须再次核对接收方和文字范围。
- 逐个核对模型设置页面、一句话设置和实际请求。未知模型沿用旧版保守预算和手动上限约束，省略未经核实的思考参数。核对界面明确说明思考强度、输出额度和正文长度的关系。混合音轨产生按时间排列的文字，不能据此判定发言人。
