# 个人工作台与会议

## 窄侧栏，320 px
```text
[导航]   当前对话         [个人工作台 ↗]
─────────────────────────────────────
对话
…
[消息输入                         🎙]
```
入口占用原状态栏一处，保留纵向空间。点击工作台复用完整页。点原“会议”直接定位会议页。身份变化、跨窗口或有待确认动作时，不能转移未提交授权或重复启动采集。

## 工作台首页，宽屏
```text
个人工作台     今日   待办   活动记录   会议   资料
────────────────────────────────────────────────
[开始会议]   [录屏]   [实时转写]   [翻译]
今日待办                      聊天中发现 · 待整理
□ 提交方案                    核对原文 → 确认待办
最近会议                      [导入录音]
```
沿用原待办和活动存储。首页呈现用户要完成的动作；模型配置保留在设置中。录屏可单独使用，浏览器选择显示来源；停止后可预览和保存。独立翻译用手动输入文本，会议翻译用确认的分段转写。

## 会议进行中
```text
‹ 工作台   会议名       ● 正在收音  00:31   [停止]
[麦克风]   [共享屏幕]   [字幕语言]   [译为…]
────────────────────────────────────────────────
00:04  原文…
       译文…
00:12  正在识别…
────────────────────────────────────────────────
结束后   [核对逐字稿]    [生成纪要]    [保存录屏]
```
原文与译文同段显示，翻译失败可重试，保留原文。原始录屏仅在本机保存。麦克风、共享来源音频、外部识别的接收方与文本翻译的接收方分别说明。用户选择后开始采集。切换工作台视图时保留唯一录制所有者。停止共享、断线、取消和关闭页面要有明确收尾及部分结果说明。

## 语音验收
分别走聊天听写、实时会议和文件导入。记录点击、设备就绪、首个采样、首次提交、首个可见文字及最终结果，用首音节紧贴起点且有已知原文的录音，在冷、热启动对照。原始样本与转写分别核首句，可定位采集或识别损失。获准后立即接收音频，以有界缓冲覆盖初始化，缓存满即停止，保留从首样本开始的连续前缀，提示启动超时及重试；准备阶段显示实际状态。支持流式的服务显示临时字幕，批量服务按段显示，不冒充逐字流式。不得静默降级或改变授权目标。对比同音频前后延迟，并检查停录尾段、排序、修订及故障恢复。

## 发布验收
真实 Chrome 窄栏和工作台操作，核聊天候选到待办、录屏保存回放、实时字幕和翻译、真实录音到纪要。执行仓库平台检查、代码评审、主线和发行流程。真实服务验证记录实际模型和耗时，不将模拟结果计为通过。

## 实现与验收细则

- 顶部状态栏就是侧栏现有的第一行。320px 下标题可省略，导航、输入和工作台按钮可用键盘触达。工作台在当前 Chrome 配置中打开独立扩展标签页，优先聚焦已有页，侧栏和聊天草稿继续保留。旧会议按钮直达该页的会议区。
- 完整工作台标签页持有设备和 MediaRecorder，内部页面切换保留挂载。跨窗口通过扩展级互斥和 Companion 会话身份防止双采集；两个同时开始只应有一个成功，另一个显示返回当前会议。刷新或关页结束此次捕获并标记中断，可找回已提交文字和录制分块。身份变更重新确认接收方。
- 就绪状态按“选择设备 → 准备麦克风 → 正在收音 → 正在整理 → 已结束”显示。取得音频后的首次设备回调立即计入最多两秒本地缓冲。超限停止并提示重试，禁止覆盖开头。测试在第一个回调注入已知首词，故意延迟服务启动 500ms、1500ms，比较送入识别的样本，要求无缺失、无重复。断线或取消时释放缓冲，未经确认不得对外发送。
- 真实测试采用同一设备、服务、模型和录音，冷启动与热启动分开各三次，报告每次首字延迟和停止到最终文字耗时。首句与末句人工逐字核对。实时模式采用开头即说话的固定音频，从首个有声样本到首个可见非空字幕目标 3 秒以内，超时如实记录；文件导入单独报告总时长。失败不得降低目标判绿。
- 录屏跟随浏览器来源选择，默认不录系统声音；用户显式选择带音频来源才混入共享音频。停止共享触发录屏封装，麦克风转写状态单独显示。按浏览器支持的 WebM 格式按块写入本机，空间不足安全停止并显示能恢复的范围；导出后用户可手动清除。权限拒绝和设备拔出要可见，不产生伪成功。
- 翻译启动前显示文本接收服务、模型、目标语言，保存逐段原文。修订按片段 ID 和版本覆盖过期译文，失败显示重试；停止采集后等待已提交结果，取消停止后续请求。网络断开仍可查看已保存内容。原始录音导入复用已支持格式及现有逐段授权。真实验收包含一次拒绝和一次中断恢复。

初始四个动作分别进入含纪要的会议、单独保存视频、仅生成文本、手工翻译。导入区显示当前实现支持的文件类型和限制，资料继续使用原材料索引。待办沿用现有证据引用与候选确认事务；原来源已清理时显示缺失，并保留正式事项。纪要沿用既有逐字稿、模板、接收方预览与确认流程，配置缺失时提供设置入口。已生成内容在原文修订后标记过期。Windows、macOS 及 Linux 以实际浏览器可选共享来源为准，用户未选共享声音时只录明确选中的音轨。

用同源 Web Lock 绑定录制标签页生命周期，标签页崩溃由浏览器释放锁，Companion 按原连接回收录音会话；新页只能从已提交的片段恢复，重新采集须再次操作。请求绑定当前用户配置、目标、会话和本次用户手势，任何变化使待确认请求失效。以 IndexedDB 的录制 ID、顺序号保存视频块，保留至导出后用户清除；每次写入处理配额错误。权限撤销或设备拔出立即停对应轨道，保留已写数据；崩溃后能否播放须用实际文件验证，无法封装时标记部分恢复。浏览器标签页关闭提示与已提交数据恢复分别测试。

独立实时转写复用会议的采集所有者与逐字稿存储。停止后进入逐字稿核对页，可在最近记录中重开，纪要为可选后续动作。单测 2 秒缓冲之外的首个样本触发停止和重试提示，已缓存前缀保持原顺序，超过容量的尾部不采纳。临时字幕只来自实际识别结果，首段 3 秒指标分别报告各服务，未达标禁止标记实时体验通过。
