# 主对话持续监督与子线程回收

GitHub: #837

父对话状态由当前 run 所属的 worker 和已有回收记录组成。计划是可选的。父对话等待 10 分钟后，立即在原对话记录已回收摘要与未完成项。等待结束不会改变 worker 的状态。

Companion 继续跟踪超时留下的 worker。实际执行版本稳定结束后，读取原回收路径并在主对话附上进度和下一步判断。已授权在运行的工作继续；新的派发和改变执行范围使用现有工具及确认。后台判断仅使用一次有界、无工具的模型请求；断线不会影响本地收集。重启后可恢复状态和回收，有界判断在缺少原模型会话配置时使用确定性说明。新的用户执行、暂停、取消及安全阻断优先。

主对话可显式标记已经交还结果的 worker 不再需要，并设置回收等待秒数。默认在交还结果后保留 180 秒。只回收与已交还结果同版本、实际空闲的 worker。保留历史、结果引用与派发次数，不关闭浏览器标签页。版本变化时旧回收标记失效。

回归覆盖三 worker 中两个先完成、第三个晚到并触及轮数上限的时序，以及重复终态、旧执行、暂停、停止、重连和默认回收窗口。
