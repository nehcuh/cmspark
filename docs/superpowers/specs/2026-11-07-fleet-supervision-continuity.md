# 主对话持续监督与子线程回收

GitHub: #837

父对话状态由当前 run 所属的 worker 和已有回收记录组成。计划是可选的。父对话等待 10 分钟后，立即在原对话记录已回收摘要与未完成项。等待结束不会改变 worker 的状态。

超时后，主对话提供「继续等待」和「先生成阶段报告」。继续等待时，所有待跟踪任务结束后汇总，等待中也可以改选阶段报告。先生成阶段报告时，Companion 用已收回的结果出报告，并继续跟踪剩余 worker。晚到的可用结果会更新状态并提示「合并到报告」或「暂不合并」。每次合并都由用户选择。

Companion 沿用原回收路径，校验当前执行版本。已授权的工作继续运行。新的派发和改变执行范围沿用现有确认。报告使用有界、无工具的模型请求，缺少原会话模型配置时从已收回结果生成确定性报告。断线和重启后仍可恢复跟踪与选项。新的用户执行、暂停、取消及安全阻断优先。

主对话可显式标记已经交还结果的 worker 不再需要，并设置回收等待秒数。默认在交还结果后保留 180 秒。只回收与已交还结果同版本、实际空闲的 worker。保留历史、结果引用与派发次数，不关闭浏览器标签页。版本变化时旧回收标记失效。

回归覆盖三 worker 中两个先完成、第三个在主对话等待超时后正常返回或触及轮数上限的时序，以及重复终态、旧执行、暂停、停止、重连和默认回收窗口。
