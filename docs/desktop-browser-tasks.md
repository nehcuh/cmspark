# 原生工作台：当前对话的浏览器任务

这是 0.6.14 开发源码中的 #476 第 6 片，不会更新安装包、启动浏览器或复制登录资料。当前源码须经独立复审、精确 head CI 和真实 Windows/macOS／扩展验收；受控 DOM/API 接口测试不代表真实浏览器已运行，也不代表整票完成。

先在“对话”打开一条对话，再进入“浏览器任务”。连接状态仅统计当前已认证的扩展 socket，不联系页面；`single_peer` 不证明该已加载 build 支持本次固定元数据协议，同为 0.6.14 的旧已加载扩展也可能不响应。只有成功读取快照并确认选择后，才可使用表中受支持的后台读取。未确认时须核对匹配的扩展 build 并刷新已有扩展，不按版本串猜测兼容性，也不自动打开 Chrome。点击“读取当前对话的候选标签页”后，最多显示 20 个候选、来自最多 20 个当前扩展；它们是候选，不能冒称该对话已在使用所有页面。标题／主机名按文本显示，不输出完整 URL、原始 tab/window ID 或授权材料。

明确选择“保持背景”或“显示此标签页到前台”。选择本身不发送消息、不授予工具许可。前台只对所选扩展、标签页及窗口发起一次显示；失败、失联或观察不符表示未确认，不自动重试、恢复焦点或切换其它页面。已经发出的 Chrome API 无撤销保证；请求级取消只能阻止已收到撤销之后的后续操作，不能宣称发送 cancel 已被扩展接收。

选择必须在同次读取起算最多 15 秒内返回同一对话明确发送。回执完成、切回聊天、重新连接或工具调用均不能延长该期限。发送时才将选择绑定到真实 canonical 运行；绑定成功后模型耗时可以超过这个选择期限，但仅保留该运行原有寿命／预算。完成、停止、失权、换对话、文档更换或断连后不可交给下一个运行。新的页面读取工具仍受原总预算与当前身份检查，不自动重获租约。

| 操作 | 当前行为 |
| --- | --- |
| 连接状态／标签页元数据 | 只读，不附加 debugger、不执行页面代码、不聚焦 |
| `get_page_text` | 背景可用，只路由到已选当前 peer/tab；保留原 CDP／scripting 读取、清洗和所有权限门 |
| 明确显示当前标签页 | 必须明确选择前台；核对当前导航，再调用所选 tab/window 的已有激活 API |
| 其它浏览器操作、未知操作 | 不可用，在 extension/image 辅助派发前拒绝；没有背景失败自动前台回退 |

本限制不授予本地工具或 MCP 权限；这些工具继续使用原独立策略和确认。原通用原生工具确认仍拒绝。原 run-progress 步骤、plan_readonly、企业范围、URL、L2、安全清洗、独占租约等门禁保持。已有 SOFT／待确认／强制释放或冲突租约不提升、不续期、不清确认；复用既有 HARD 租约不由本视图释放。

扩展仅为已观察 tab 保留至多 64 个会话内导航 nonce。观察到 loading、URL 变化、移除、重启或容量淘汰会使旧选择失效；loading／pendingUrl 不明时拒绝。它不是跨浏览器原子 document attestation，不能证明未观察到的事件竞态不存在。至多 64 个扩展请求同时在途，取消但 Chrome API 尚未返回的调用仍占容量；容量耗尽只拒绝，不自动重试或扩权。

切页、换对话、文档／连接变化会通过原生专属 `desktop.browser.retire` 帧先撤销服务器对应上下文；renderer 无权发送此方法。回到同一对话只撤销待视图操作，不抹掉已经明确选择的下一运行策略。丢失 ACK、迟到回执与 A/B/A 不会自动重放；请重新读取并核对，草稿保留。
