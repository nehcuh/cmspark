# CMspark macOS App Replace

> **Generated from S85/S87/S102/S103.** Confidence: high | Occurrences: 4+ | Failures were real.

**Violating the letter of these bans is violating the spirit.** Generic macOS advice (`xattr -cr`, `pkill -f`) is wrong here.

## When to Use

- User asks to 编译 DMG / 替换 `/Applications/CMspark.app` / 换装 / 热替换 companion
- Agent is about to `xattr -cr`, `pgrep -f /Applications/CMspark.app`, or `~/CMspark.app.bak-*`

**Not this skill:** Windows NSIS, Linux zip, Chrome-only reload with no .app swap.

## Sequence

Announce: using cmspark-macos-app-replace.

1. `nvm use 22` then `make package-macos` from repo root. Staging app is `dist-package/dmg-staging/CMspark.app` (same tree as the DMG). Size with `/usr/bin/du` (`du` may be `dust`).
2. Verify staging: `codesign --verify` + A6 **one** CDHash on `Contents/MacOS/CMspark` and `Contents/Resources/cmspark-host`.
3. Stop live app: `"/Applications/CMspark.app/Contents/Resources/node" "/Applications/CMspark.app/Contents/Resources/cmspark-agent.js" daemon stop` → `osascript` quit `CMspark` → **per-PID** `kill -9` from `ps -axo pid=,command=` rows whose command contains `/Applications/CMspark.app`. Wait until none remain. Never `cmspark-host … daemon stop`.
4. `ditto` staging onto `/Applications/CMspark.app`. **No bak** unless the user asked in this turn.
5. `xattr -dr com.apple.quarantine /Applications/CMspark.app` only.
6. `codesign --verify` installed bundle; CDHash must **match staging**. Then `open -a CMspark`.
7. Confirm: Info.plist version == `companion/package.json`; daemon listens `127.0.0.1:23401`.
8. Tell the user to **Reload** unpacked extension `chrome-extension/build/chrome-mv3-prod/` (DMG does not reload Chrome).
9. If they asked to delete backups: `rm -rf ~/CMspark.app.bak-*` only. Do not invent a bak in order to delete it.

If `make package-macos` dirties `host-integrity.ts`, leave it uncommitted unless asked.

## Hard bans

| Never | Why | Do instead |
|-------|-----|------------|
| `xattr -cr` | SIP `com.apple.provenance` on whisper/libggml → `Permission denied`; `set -e` aborts mid-swap | `xattr -dr com.apple.quarantine` |
| `pgrep -f` / `pkill -f` `/Applications/CMspark.app` | argv of the wrapper contains that path → SIGTERM self | `ps` then `kill -9` **that PID** |
| `kill $(ps …)` one shot | empty table / race | one PID per `kill` |
| `~/CMspark.app.bak-*` | user lock: no bak | rollback = this run's DMG / staging |
| `codesign --force` after ditto | new CDHash, TCC identity breaks | trust staging signature |
| `pgrep -f cmspark-agent.js` global | may kill repo `companion/dist` daemon | only `/Applications/CMspark.app` paths |
| Claim done after ditto only | unpacked side panel stays old | version + `:23401` + tell user to Reload |

## Rationalizations

| Excuse | Reality |
|--------|---------|
| "`xattr -cr` is the Gatekeeper cleanup" | It hits SIP. Quarantine-only. |
| "`pkill -f` makes sure it's dead" | It kills this agent. Per-PID. |
| "Bak is reversible / professional" | User forbade bak. DMG is the rollback. |
| "Re-sign after ditto to be safe" | Breaks A6 CDHash / TCC. |
| "Companion 0.5.x means the extension is current" | Chrome unpacked is a second install. |
| "`du -sh` is fine" | Shell `du` may be `dust`. Use `/usr/bin/du`. |

## Red Flags — STOP

- Command contains `xattr -cr` or `pgrep -f /Applications/CMspark.app`
- Creating `CMspark.app.bak`
- `codesign --force` on `/Applications/CMspark.app`
- "I'll reload the extension later" then claiming dogfood-ready
- `pkill -f CMspark`

## Verify before "done"

- [ ] Staging and installed CDHash equal (A6)
- [ ] Plist version == package.json
- [ ] `ws://127.0.0.1:23401` up
- [ ] User told to Reload unpacked extension
- [ ] No new `~/CMspark.app.bak-*`
