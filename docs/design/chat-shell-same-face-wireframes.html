04 「贴回」两套引擎（本票不锁，线稿先画诚实）

Chrome 窗引擎

弹出 = 扩展 windows.create 小窗，里面仍是 ChatShell。

贴回 = 用户点按钮（手势）→ sidePanel.open + 关小窗。真贴回。

托盘要点这只窗，Chrome 必须在跑。热键在 Chrome 没焦点时变弱。

OS HUD 引擎

弹出 = 打开已挂 ChatShell 的 overlay HTML / Swift HUD。

贴回 不能一键（F-I-4：Companion 打不开侧栏）。文案：「请点工具栏的 CMspark」。

托盘 / 热键原生。看起来更像截图 5，但不像 Gemini 的装卸。
