召唤条，不是迷你插件

看山纸面 + Codex / 千问办公 / WorkBuddy 的分区：输入永远在底，左边一次只打开一类。这是给 AppKit 对照的高保真，不是又一个 HTML 产品窗。

对话
回车发送 · Shift+Enter 排队 · # 搜标题 · ⌃ 收起

视觉合同（看山 · Operate）

  • 纸面白 + 锌灰字 + 靛蓝只用于选中/焦点
  • 8px 节奏；轨钮 / 列表行 / 底栏按钮 ≥ 44px
  • 图标全 SVG 描边，不用 emoji 当导航
  • 焦点：白底上 2px 靛蓝环；尊重 prefers-reduced-motion

交互

  • ⌄ 展开，⌃ 收起，Esc 关窗
  • 轨一次一类；列表只渲染该类
  • 空态教用法，不放插画角色（HUD 是工具条）
  • 批准不进此窗；网页 CDP 仍走扩展
