# 编程接力 · 产品形态重审（多路对抗合成）

> **日期**: 2026-08-13  
> **触发**: 用户真机反馈（工作区无响应 / 要看 Agent 流转 / GitHub 联动 / 本地配置 / 设置怪异）  
> **方法**: 4 路独立对抗 agent — JTBD · UX · Trust/架构 · 反膨胀  
> **地位**: 修订方向 SoT；**不**推翻 ADR-020/022/025 安全锁；**修订**观察面过薄与入口错位  
> **相关**: [原设计](acp-coding-handoff-product-design-2026-08-13.md) · [ADR-025](../adr/025-acp-coding-agent-client.md)

---

## 0. 一句话裁决

| 问题 | 裁决 |
|------|------|
| 方向（浏览器证据 → 本机写码）对不对？ | **对** — 保留 |
| 要不要 Side Panel IDE / 第二 runtime？ | **不要** |
| 当前「任务包 Modal + 设置开关 + 薄 Chip」够不够？ | **不够当产品形** — 零件可以，脊柱不行 |
| 用户要的「独立 Agent」是什么？ | **编程工作台（观察面）**，不是第二聊天/IDE |
| 设置里的「编程助手」怪不怪？ | **怪** — 日常应在 **场景+工作台**；设置只留 CLI 开关 |

**产品句：**

> 我们不做独立 Agent 产品面；我们做 **编程场景的观察工作台**（对齐会议工作台）。  
> Chip 负责「还在跑 / 能停」；工作台负责「跑到哪了 / 发现了什么」；写码仍在外部助手。

## 1. 用户 5 条反馈 → 诊断

### 1.1 「选择工作区」无响应 — **真 bug（接线）**

```text
用户点「选择工作区」
  期望: 系统文件夹对话框
  实际: 关 /code 模态 → 打开「场景」面板
        真正的 pick 在 PacksPanel 里，无聚焦、无第二引导
  感知: 点了没反应
```

**根因**（已读码确认）:

```text
App.tsx onRequestWorkspace =
  setCodingHandoffOpen(false) + openPanelForce("packs")
  // 从不发 workspace.pick
```

**P0 修复**: 模态内直接 `workspace.pick`；**不关**模态；全局处理 `workspace.pick_result` → 刷新线程。

### 1.2 「ACP 启动后应有独立 Agent 看操作流转」

| 用户要的 | 不是 |
|----------|------|
| 看见阶段 / 读了哪些文件 / 发现与提案 | 第二聊天 runtime |
| 能停、能开详情 | Monaco / 伪终端 |
| 会议级「工作台」 | 底栏常驻 Agent Tab |

**裁决**: Composition 内 **编程工作台**（会议同构）= GO；独立 Agent 面板 = NO-GO。

### 1.3 GitHub 网页联动

| 能力 | 裁决 |
|------|------|
| 从页解析 `owner/repo` 提示 | GO |
| **关联已有本地目录**（folder-picker） | GO · 最高频 |
| **复制** `git clone …` | GO · 零新爆炸半径 |
| 产品化「一键 clone」写盘 | GO-WITH-GATES 后期（专用工具 + L2）；**禁止** free shell 当主按钮 |
| 页 URL 自动改 `workspace_root` | NO-GO（只能建议） |

### 1.4 关联编程 Agent 应读本地配置

| 允许 | 禁止 |
|------|------|
| PATH / 已知路径探测可执行文件 | 读 `~/.claude` 密钥/会话史灌 LLM |
| UI 只显示 basename；全路径仅 Companion | 聊天里泄绝对路径 |
| config 优先 + 用户手势 adopt | 设置页变成 Agent 商店 |

### 1.5 设置怪异 → 独立编程场景？

**GO**: 场景（Pack）「编程接力」= 第一公民入口 + 工作台。  
**设置**: 仅「本机 CLI / ACP 总开关 / 探测」— 副路径。  
**不要**: 底栏新 Tab「编程」。

## 2. 四路对抗共识

| 路 | 核心结论 |
|----|----------|
| **JTBD** | 脊柱 = 页上下文 + 绑仓 → 外派 → **可观察会话** → 页上验收；不是 Modal→复制→设置 |
| **UX** | 工作区 bug 是信任崩；`/code` 应绑仓优先；运行态 = FocusBand + 详情/工作台 |
| **Trust** | 独立 Agent 主面板 = Autonomy 污染；clone 默认 copy；自动绑仓 NO-GO |
| **反膨胀** | 警惕半 IDE；默认薄接力；工作台是观察不是编辑器 |

**冲突仲裁**:

1. 反膨胀「砍 apply/followup」vs 用户「要看流转」→ **保留可观察工作台**；apply 仍 HITL 且非默认主 CTA。  
2. 「独立 Agent」vs 非 IDE → **工作台 ≠ Agent 产品**。  
3. 原 SoT C2/C4 过薄 → **修订**：禁止 ACP 运行时面板；**允许**会议同级编程工作台。

## 3. 推荐产品形态（三层表面）

```text
┌─────────────────────────────────────────────────────────────┐
│  A. 仓库条（Page ↔ Repo）                                     │
│     GitHub/GitLab 页：org/repo · 绑定态 · [关联][复制clone]    │
│     非代码页：仅「选本地目录」                                  │
└─────────────────────────────────────────────────────────────┘
                              │
┌─────────────────────────────────────────────────────────────┐
│  B. 场景「编程接力」(Pack)                                     │
│     唯一心智：配方 + 工作区契约 + /code + 打开工作台             │
│     与 AppSec / 会议 并列，不进底栏新 Tab                      │
└─────────────────────────────────────────────────────────────┘
                              │
┌─────────────────────────────────────────────────────────────┐
│  C. 编程工作台（Workbench · Context 面板）                     │
│     绑定 · Agent 探测 · 任务 · 会话时间线 · 发现/提案 · 停止    │
│     = 会议工作台同构 · 不是 Monaco · 不是第二聊天              │
└─────────────────────────────────────────────────────────────┘

FocusBand:  ● 编程 · Claude · 3:12 · [工作台] [停止]   ← 急停级槽
聊天流:     Offer / Handback 摘要卡
设置:       CLI 开关 + 探测镜像（日常不进）
```

### 与会议同构

| 会议 | 编程（提议） |
|------|----------------|
| 场景「会议记录」 | 场景「编程接力」 |
| 会议工作台 | 编程工作台 |
| FocusBand 不吞全文转写 | FocusBand 不吞全文 token |
| 产物：纪要 | 产物：任务包 / 审查发现 / 起草摘要 |

## 4. ASCII 主流程

### 4.1 冷启动绑仓（修 bug 后）

```text
用户 /code
      │
      ▼
┌─ 编程接力 · 任务包 ─────────────────┐
│ 工作区: ⚠ 未绑定                     │
│ [ 选择工作区… ]  ──workspace.pick──► │ 系统文件夹对话框
│         │ 成功                        │
│         ▼                             │
│ 📁 cmspark  [更换]                    │
│ 任务摘要 …                            │
│ [复制任务包]  [启动·审查]（需 ACP+披露）│
└───────────────────────────────────────┘
      │
      ▼
SceneStatusBar: 工作区 cmspark
```

### 4.2 GitHub PR → 审查

```text
Tab: github.com/org/repo/pull/42
      │
      ▼
  仓库条: org/repo · PR #42
  本地: 未关联？
      ├─ [关联本机目录] → picker → bind
      ├─ [复制 git clone …] → 用户终端
      └─ (后期) [克隆到…] → L2 专用工具
      │
      ▼ 已绑定
  [审查此 PR] → Confirm(HITL)
      │
      ▼
  FocusBand ● 编程 · 审查 · [工作台][停止]
  工作台时间线:
    · 读 src/foo.ts
    · 对照 PR 描述
    · 发现 3 条
      │
      ▼
  Handback 卡 → 对话
  [贴回] [侧栏再验页面]
```

### 4.3 Staging bug → 起草

```text
staging 复现（L1 对话/截图）
      │
      ▼
  Offer / /code / 场景编程
      │
      ▼ 必须先真绑仓（禁止沙箱冒充 monorepo）
  任务包预览（可编辑）
  模式: 审查 | 起草（脚注: 外部进程可能写盘）
      │
  ┌───┴───┐
  复制外贴  HITL 启动 ACP
      │         │
      └────┬────┘
           ▼
  工作台看进度 → Handback
  用户: staging 再点验收
```

### 4.4 看助手 Live（用户核心诉求）

```text
running
   │
   ├─► FocusBand（永远可停；Confirm/急停可压过）
   │      点 [工作台] 或 chip
   │
   └─► 编程工作台
         ┌──────────────────────────────┐
         │ Claude · 起草 · ~/…/repo      │
         │ ⏱ 3:12  [停止编程会话]        │
         │ 阶段: 采证→分析→提案→待应用    │
         │ 最近步骤 (≤5):                │
         │  · 读 app/api.ts              │
         │  · 搜 "timeout"               │
         │  · 提案 app/api.ts +12        │
         │ 涉及文件: 点行可外开           │
         │ 隐私: 可能上云 · 非沙箱担保    │
         └──────────────────────────────┘
   │
   ▼ closed
  Handback 摘要卡；chip 保留追问/应用(HITL) 或淡出
```

### 4.5 信任边界（不可破）

```text
  浏览器页 (不可信 DATA)
         │
  Companion 唯一 tool-loop
    ├ Pack / 任务包
    ├ ACP Client ──stdio──► 外部 CLI (OS 进程, 非 CMspark 沙箱)
    └ Outbound MCP ◄──────  外部 Agent 租浏览器 (方向相反, 勿混)
         │
  workspace_root ← 仅用户 folder-picker
  写盘 ← 仅 L2 gated apply 或 外部 Agent 自写
```

## 5. GO / NO-GO

| GO | NO-GO |
|----|-------|
| 修 workspace.pick 接线 | 「选择工作区」只跳场景面板 |
| 场景「编程接力」+ 工作台 | 底栏常驻「编程/Agent」Tab |
| FocusBand + 工作台时间线 | Side Panel IDE / Monaco / 伪终端 |
| 页 repo 提示 + 关联目录 + 复制 clone | 页自动改 workspace_root |
| config 优先探测 basename | 读本地密钥/会话史灌模型 |
| 设置 = CLI 开关 | 设置当日常主入口 |
| Outbound 与接力对照表 | 「统一 Agent 平台」 |
| HITL 启动/apply | cruise 跳过 / 静默写盘 / free shell |

## 6. 分期

### P0 — 信任（1–2 天）

1. `/code` 内直接 `workspace.pick`，不关模态  
2. 全局 `workspace.pick_result` → UPSERT_THREAD  
3. 成功 flash basename；失败/取消可见  
4. 设置副文案：「日常用 /code；此处仅 CLI」

### P1 — 日活形（1–2 周）

1. 场景卡片「编程接力」+ **打开编程工作台**  
2. 工作台：绑定、Agent 探测、任务、时间线、停止  
3. Chip CTA「工作台」  
4. GitHub strip：关联本机 + 复制 clone  
5. config-first Agent 列表

### P2 — 条件解锁

1. 结构化 `steps[]` / `files_touched` 事件  
2. 专用 `repo_clone`（L2·固定 argv）  
3. Cockpit 宽 diff 只读查看  
4. 受控 apply 体验打磨（仍非静默）

## 7. 对用户五问的直接回答

1. **选择工作区无反映** → 实现 bug：跳场景未调 pick；P0 修。  
2. **独立 Agent 看流转** → 做 **编程工作台**（会议同构），不做第二 Agent 聊天。  
3. **GitHub 联动** → 关联本地 + 复制 clone 优先；真 clone 后期 gated。  
4. **读本地配置** → 探测 CLI 路径/可用性；不吸密钥；config 优先。  
5. **设置怪** → 日常入口迁到 **场景·编程接力**；设置降级为 CLI 开关。
