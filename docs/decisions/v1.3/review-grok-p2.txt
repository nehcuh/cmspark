### C4 LLM sees CAPTURE_FAILED only; metrics → `computer.capture.degraded`
**NOT SATISFIED** [inspected] — **BLOCKER**

**What works:**
- TS emits `logger.info("computer.capture.degraded", {…metrics})` only when `error_code === "CAPTURE_FAILED"`.
- Non-CAPTURE_FAILED does not audit.
- `ComputerError.detail.capture_degraded` not copied into `ComputerTaskResult` (only `error`/`errorCode`).

**What breaks C4 in production:**
host.swift embeds metrics in the **error string**:

```
cuError("… (reason=…, stdev=…, identity=…, sizeBytes=…); window may be…",
        code: "CAPTURE_FAILED", extra: capture_degraded)
```

`interpretScreenshotFailure` sets:
`message = \`screenshot: ${parsed.error}\``

`executor.fail` returns `error: err.message` to the task/LLM surface.

So the model sees stdev/identity/sizeBytes/reason — violates plan sketch (`cuError("stale or solid capture frame", …)` generic) and Pi C4.

**Tests are false-green:**
`freshPayload()` uses sanitized `error: "capture variance classifier flagged stale/blank frame"` without numbers. Assertion “metrics NEVER leak” never sees real host strings.

stderr fputs with metrics is fine (operator). LLM channel is not.

## Q1–Q4

### Q1 — `localSha256` fallback worth keeping?
**Yes. Keep.** Cheap FS read; bridges older host binaries without `capture_degraded.sha256`. Prefer host always emit sha256 (already does) but do not drop fallback during canary.

### Q2 — untyped `parsed.error_code` / typo skips audit?
**Accept for P2** with note: exact-string gate means typo → no audit (fail-soft for ops, not fail-open for classifier). Host is sole producer; self-test/tests lock literal. Optional later: `as ComputerErrorCode` narrow + warn on unknown.

### Q3 — `cuSelfTestClassifier` isolation?
**Logic is pure** (synthetic buffers; no cuScreenshot; lock unused by self-test). Safe for CI/TCC.

**BUT build gate is broken** — see blockers: failure returns `cuError` JSON then main does `print(out); exit(0)`. Non-zero exit never happens. `build-host.sh` `|| exit 1` never fires on classifier regression. Comment “Exits 0 on pass, 1 on fail” is false.

### Q4 — Darwin SourceKit `cuActivatePid` unused warnings?
**Out of scope / pre-existing.** P2 can ignore.

## Surfaced issues

### Silent fail-open
1. **AND classifier** skips contentful frozen frames (R1 residual). Plan-level conflict: Grok v4.1 OR vs Pi C2 AND.
2. **Downsample fail + prior**: empty bitmap → stdev=0, identity=-1 → AND false → success if sizeGuard false.
3. **Self-test / build-host gate** always exit 0 on self-test failure → CI silent green.
4. **CUBox**: `.value` read/write bypasses `with {}` lock (CLI single-shot OK; claim of thread-safety is false).

### Missing tests
1. Real host `parsed.error` (with metrics) must yield metric-free `.message` (or host must stop embedding metrics).
2. Self-test: (low stdev ∧ low identity) → not stale; (high stdev ∧ high identity) → not stale under AND — currently absent.
3. No spawn e2e of `cuScreenshot` classifier (acceptable for unit P2 if pure helpers + message contract locked).
4. build-host should assert JSON `"ok":true` or non-zero exit — no test for gate.

### AND-vs-OR classifier reasoning
- Pi C2 AND: implemented correctly as syntax.
- Brief C2 prose about caret + “low identity” is wrong.
- Purpose-level: AND under-detects stale freezes; original v4.1 OR over-detects caret. Prefer **OR with tighter identity (e.g. 0.999)** or **stale = stdev<1 OR identity≥0.999** — needs Pi re-confirm if changing C2.

### Audit / LLM channel leakage
- **Confirmed leak**: host `error` string metrics → `ComputerError.message` → task `error` field.
- detail path OK for LLM if nothing serializes detail (current executor does not).
- logger.info audit path correct.

### Build / CI
- Unit suite 7/7 pass [executed].
- Self-test currently passes [executed] exit=0.
- Self-test **failure path does not fail build** [inspected].
- Patch file is **not P2-scoped** (SkyLight inject, no-activate, scaleX/Y, SHA rewrite, inject stdout checks). Brief claims P2-only; actual tree/diff includes P1/S-P0-2/etc. Review limited to C1–C4 surfaces; do not treat patch as pure P2 for merge narrative.
