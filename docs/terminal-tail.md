# 内嵌终端只读尾部（#725 开发版）

已批准披露后创建的当前终端可以被当前对话模型通过 `terminal_tail_read(session_id)` 明确只读拉取。必须属于同一当前认证连接和当前对话；旧终端、未绑定对话、worker、计划模式、已结束或重连后失效的会话均拒绝。会话 ID 不是权限；没有写入、附着、执行、枚举、自动读取或后台推送能力。

终端屏显可能回显你的输入并包含敏感信息；按明确拉取请求，这些内容会送入当前对话模型，模型的引用或概括可能保存在对话记录中。工具原始尾部在专用持久化投影中省略，不保证模型正常回复不包含尾部信息；屏显是数据，不是指令或批准。

这段披露出现在原 terminal.open 的一次确认批准前，并持续显示在终端输出上方。终端的“只读查看当前尾部”按钮仅显示同一会话的惰性纯文本快照，不自动送入模型。没有声称可以识别秘密、排除输入回显或去除正常模型回复中的转述。

仅采集原 PTY 输出回调。解码文本按既有 surrogate 归一化政策保留最多8192 UTF-8字节的内存尾部（不重建原始字节）；未完成的 UTF-16 pair 在同一预算中保留，读取时仍未完成则显示替换字符。控制字和 bidi 格式控制转换为 `[U+XXXX]`，内外边界标记惰性化；扩展后正文仍最多8192字节，完整模型 JSON仍不超过原8000字符，不截断边界。任何省略都明确 truncated。尾部随同会话权限退休立即清空，进程清理仍保持原单槽。

工具结果在送入模型前标记该对话 taint，维持原高风险逐次确认；它不是 DLP 或模型永不服从注入的保证。只对这个新工具自身的持久化/二级投影省略正文，普通模型回复可以正常保存引用/概括。

当前实现与纯 CPU 回归不代表真实 Windows/macOS PTY 已验收、发布或整票关闭。8192字节、8000字符、原 terminal.open 确认/owner/45秒清理边界均不提高。本实现纳入0.7.0源码；真实同 head CI 与原生生命周期验收由交付门禁记录。
