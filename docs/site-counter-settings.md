# 查看和重置站点失败计数

在侧栏选择对话，打开设置 → 安全与信任 → 站点失败计数，点击「刷新站点状态」。页面显示当前浏览器标签的准确 HTTP(S) 站点、该对话的失败计数和最后错误码。不同协议、子域名和非默认端口分别计数；服务端重新读取当前标签，客户端的域名提示不决定操作范围。

「重置当前对话此站点的失败计数」只把这一项运行计数归零。最后错误码仍保留；未分类的错误显示 UNKNOWN。计数归零没有证明站点已经恢复。已有定位失败规则、历史经验、标签连接限制和权限仍然有效，界面会显示相关限制。

当前对话的任务、浏览器工具或人类确认尚未结束时，重置会被拒绝。等待任务结束后，可刷新状态并再次手动操作；界面不会自动重试重置。切换对话、标签、页面或断开连接会使旧状态失效。文件页、浏览器内部页和无法确认的标签不提供重置范围。

运行计数目前按对话保存在进程内；新对话不会继承另一个对话的运行计数。自动保存的定位失败经验属于另一层，#535 的通道证据修复与此入口分开处理。

开发验证使用已配对的专用临时 WS、真实路由和 BrowserBridge 读取生产者，以及明确标注的 Chrome/界面传输测试环境。页面路径、查询参数、凭据和原始错误不在此状态接口中返回；界面只显示站点 origin、计数和固定诊断。目标检查是有界的当前观察，不是对未来浏览器导航的原子锁，也不发放任何操作授权。
