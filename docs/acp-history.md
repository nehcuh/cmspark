# 编程接力会话清单

#732 增加最小元数据历史：面板内“会话清单”只读显示当前对话的 Agent 标识、时间和会话状态。目标、项目路径、输出和命令不会存入历史文件。它不恢复进程或授权，也不提供旧会话直接执行按钮。

服务重新启动后，没有当前运行句柄的旧非终态记录显示“已中断；无法恢复原进程关联”。“会话已关闭”表示记录的桥会话关闭，不证明外部 Agent 的整个任务完成。原 start/apply 等确认流程保留。

该功能仅在 `acp.enabled=true` 时访问历史。关闭时不创建、更新或发布历史内容。文件不可安全验证、损坏或写入失败时，面板明确提示持久性未获确认；当前 ACP 控制仍按原流程处理。

文件为已有私有 Companion 数据目录中的 `acp-history.json`，有限条目和大小，采用私有临时文件及原子替换。Windows 必须通过真实只读 ACL 检查，不能用 chmod 模式位代替 NTFS 隐私。不自动改权限或修复损坏文件。

本条记录实现范围；真实 Windows ACL、Companion 重启和侧栏刷新验收仍须单独完成，不以源码/CPU 测试宣称通过。自动重连或 CLI resume 不在本期。

重连后，当前查询中只剩历史记录的旧会话会撤下运行操作入口；记录本身仍可查看。查询期间新收到的同会话状态或新会话优先，不按时间戳猜测新旧，也不恢复历史进程句柄。
