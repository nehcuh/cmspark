## Safety / 急停

**PASS.** The secondaryAbort path is rendered before the primary slot inside the card:

```tsx
{slot.secondaryAbort && (
  <AbortSecondaryLine taskId={task!.taskId} taskLabel={task?.task} />
)}
```

`AbortSecondaryLine` renders a prominent button with `background: tokens.darkDangerBg`, `color: tokens.darkDanger`, and `border: 1px solid #7f1d1d`. The abort line itself uses `background: tokens.darkBg` — the same dark treatment as before. When L2 is active and confirm fires, the `resolveFocusBandSlot` function (unchanged) returns `secondaryAbort: true`, so the 急停 line appears as a dark secondary row inside the floating card. The dark abort bar inside the soft-tinted confirm card provides strong visual contrast — the 急停 is not buried.

One subtlety: the `secondaryContext` background changed from `tokens.darkElevated` to `tokens.darkBg`. This is the L1 context line under confirm (mutually exclusive with secondaryAbort per the priority machine, so it never competes with 急停). The change is cosmetic and does not affect safety.

## Tool cards

**PASS.** The diff replaces the `borderColor: statusTone` inline override (which colored all four sides) with `borderLeftColor: statusTone`:

```tsx
// Before: full-border cage
style={{ ...styles.toolCard, borderColor: statusTone }}

// After: left hairline only
style={{ ...styles.toolCard, borderLeftColor: statusTone }}
```

The base `toolCard` style provides the elevated white card with a 2px left accent:

```tsx
toolCard: {
  border: `1px solid ${tokens.border}`,         // hairline all sides
  borderLeft: `2px solid ${tokens.accent}`,       // 2px left accent (overridden by status)
  borderRadius: tokens.radiusMd,
  background: tokens.bgElevated,                  // was rgba(255,255,255,0.92)
  boxShadow: tokens.shadowSm,
}
```

Status color arrives only via `borderLeftColor`, creating exactly the "hairline left accent" pattern specified in P-G3 and §5.5.

## Nits

1. **停止 button border opacity reduced from solid to 35%.** Old: `border: 1px solid #7f1d1d`. New: `border: 1px solid rgba(220, 38, 38, 0.35)`. On the `dangerSurface` background (near-white with 8% red tint), the 35% red border is still visible but softer. This remains clearly tappable (red text + outline), but verify in a real L2+confirm scenario that the 停止 action doesn't visually recede too far next to the high-contrast 允许 (white-on-green) button.

2. **Label text contrast shift.** The compact confirm label now uses `color: tokens.danger (#dc2626)` on the transparent/dangerSurface background. On the old dark gradient, the label used `color: tokens.darkDanger (#f87171)` — lighter red on dark. The new `#dc2626` on near-white has ~4.3:1 contrast ratio (WCAG AA for normal text is 4.5:1; AA for large text is 3:1). At 11px/700 weight this is marginal but acceptable for this context — worth a visual check in the rendered panel.

3. **`font` token reference in MinimalConfirm compact.** The original code used `fontFamily: tokens.font` — this is preserved. No regression.
