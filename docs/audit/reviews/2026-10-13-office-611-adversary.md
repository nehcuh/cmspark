## Confirmed ODF defects and final closure

1. **Synchronous repeated-cell work was not admitted before parsing.** The core investigator's generated 725-byte ODS with 100000 repeated columns returned 1700017 characters in 190ms despite a 20ms cooperative timer; the single-column control was 2ms. This is evidence that synchronous dependency loops postpone timers, not evidence of a production 30-second hang or OOM. I inspected the actual upstream column loop, nonempty-row deep-copy loop, empty-tail shortcut, inline space expansion and MIME selection. The final guard charges empty columns and emitted row/column products, validates numeric/namespace/container semantics, budgets across sheets and embedded XML, and refuses the original case before the real parser. Independent nine-group guard tests preserve six valid repeated markers plus both million-row empty-tail shapes and refuse invalid counts, large text spaces, nested products, cross-sheet totals and type/fallback bypasses.
2. **The first guard counted external object XML once although independent references expanded it repeatedly.** I independently constructed a 753-byte public ODS with 90 ordinary frame references to one 100000-character MathML object, without row/column repetition attributes. The first guard accepted it; the prewarmed actual parser returned 9000028 characters in 89ms, exceeding the stated 8388608-code-unit budget. The final `checkObjectReferences` resolves actual object-entry targets using the upstream basename/suffix rules and rejects duplicate target references, including alias paths and nested frame revisits. Repetition attributes containing embedded objects also refuse. The permanent actual-parser regression now refuses this sample; a valid single reference remains admitted. I inspected the correction and independently reran the final nine guard groups and all Office/entry tests successfully. This blocker is closed, not deferred into #614.
3. **Pi reproduced attribute-driven chart expansion after the prior guard approval.** On rejected source `6aa2b973…`, Pi's 925-byte ODT chart with 24000 repeated datasets and a 16000-character `office:value` yielded a 384312000-character join and approximately 844MB RSS; the equivalent paragraph text refused.
