### S2 hard evidence — no onEvent anywhere

```
$ grep -rn "onEvent" chrome-extension/src/ → (zero hits)
```

This is the strongest single finding in the spike. Without `chrome.debugger.onEvent`, CDP `Browser.downloadWillBegin`/`Browser.downloadProgress` can **never** reach the extension. The `PRIMARY=chrome.downloads` decision is not just a default — it's the **only viable path** given the current bridge architecture.
