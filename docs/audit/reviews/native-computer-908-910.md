## 修复与机核

Windows 坐标和 UIA 输入都检查停止状态，原生输入运行期间写入 PowerShell 消费的停止文件，并在输入结束后再发面板停止回执。macOS 的 AX 与坐标输入也都登记在途子进程。集成测试经过真实 WebSocket 回执与 Windows 适配器，受控生产者核实了停止文件、回执时序及拒绝后续输入。

macOS 滚动按目标窗口转换坐标，在投递前核对实际鼠标位置、最上层窗口与 PID。真实 AppKit 接收端在客户区 (80, 70) 收到滚动（窗口坐标 (80, 110)，窗口高 180）。独立遮挡窗口覆盖落点后，宿主返回 CLICK_OCCLUDED，两窗都没有新增滚动事件。

本机观察在捕获、OCR、预览、证据写入及最终发布时复核当前授权。回归测试在本地 OCR 执行中撤权，断言返回 TASK_ABORTED、无文字结果和预览。权限窗口明确列出同一扩展连接下的所有普通对话。
