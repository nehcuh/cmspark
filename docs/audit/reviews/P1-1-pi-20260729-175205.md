### 6. Nits (non-blocking)

1. **`background/index.ts:519`** — `saveExtensionConfig(message.config || {})` executes before the companion validates the phrase. If companion rejects, Chrome local storage has an optimistic write that doesn't match companion authority. The companion remains authoritative (and restarts resync), so this is UX noise only, but it's an ordering nit.

2. **Phrase literal "我了解风险" duplicated across 3 locations** without compile-time enforcement: `companion/src/security-arm.ts`, `SettingsSlideout.tsx` `GODMODE_CONFIRM_PHRASE`, `SettingsSlideout.tsx` `ENT_B_PHRASE`. Comment-based lock-step is fail-closed (UI accepts, companion rejects → visible error) but fragile to maintenance drift.

3. **Test `readTodayLog()` uses fuzzy `includes()` with `||` fallback** — if another test logs a matching substring in the same run, assertions could false-pass. Test-only concern, no production impact.
