## Blocking issue

**B1 — Extension build is broken (TS2551).** `chrome-extension/src/sidepanel/components/FocusBand.tsx:314`: `color: tokens.textMuted || tokens.muted || "#888"` — `tokens.muted` does not exist (tokens.ts has `textMuted`, `bgMuted`, `darkMuted` — no `muted`). Verified: `npx tsc --noEmit -p tsconfig.json` exits 1; `npm run build` = `tsc --noEmit && plasmo build` therefore fails, so the batch cannot build the extension. The green test runs don't catch it because `tsconfig.test.json`'s narrow include list excludes FocusBand.tsx (which is also why N1c's "TS compiles clean" claim was wrong — the error has shipped since N1). Fix is one line: drop `tokens.muted` and use `tokens.textMuted || "#888"`.
