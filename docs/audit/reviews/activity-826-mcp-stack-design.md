## Implementation clarification for the source gate

The3/6/6-second limits are configured query/debugger termination-request deadlines. The implementation must still observe actual child close before removing its workspace or proceeding; required teardown may follow those deadlines. This is not a hard15-second end-to-end wall-clock guarantee. The source gate must explicitly adjudicate this concrete lifetime behavior, including the separate CPU dummy, rather than treating a kill request as closure. The original canonical MCP20 and all acceptance/cleanup statements are unchanged. This clarification was added after design approval and is supplied in full to the independent and actual GLM source gates; it does not rewrite their prior design verdicts.
