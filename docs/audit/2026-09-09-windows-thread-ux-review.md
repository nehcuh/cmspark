# Windows 变更复审与插件体验核查（#488）

审查范围：`4a63de56` → `947532a8`（#487）。先冻结外部变更，再由 Grok 4.6、
独立 Codex、DeepSeek V4 Pro 三路分别审查；本轮最终修复仍须 Grok + DeepSeek
独立放行。后两位外部模型组合沿用用户明确授权；没有把本机子代理冒充外部模型。

## 对评审模型的纠偏

- DeepSeek 的“零选中直接点击删除”复现不成立：按钮已有 disabled。有效触发是
  选中后 busy/filter 改变但旧选择未清理；修复依据实际复现，不依据模型投票。
- 两个外部模型对会议的部分描述不准确：Host 收起并非 #487 新增；内层直接
  finalize 也不能确保末段排空。已保存的历史片段不一定丢失，风险是尚在途末段。
- Grok 对布局的正面判断不能覆盖短屏实测高度 0；DeepSeek 的 panelMaxHeight
  effect 推断不足以定位根因。按真实浏览器布局证据修复。
- “全选替换旧选择”“CLI fallback”“redactor null/type”等观察没有形成可复现
  本批阻断。版本、CLI、参数脱敏由其所属测试及全量回归验证；不凭猜测扩大修改。
- 修复复审中 DeepSeek 又将单行删除误读为旧 thread.delete，将无 Host 的安全
  else 分支读反。补充真实组件的单行回执、独立 MeetingPanel、设置失败后重试
  三个场景，均通过；DeepSeek 重新阅读代码与证据后明确撤回，给出 APPROVE。
  初版 REJECT 原文保留，不把错误发现静默删除，也不凭实现者意见越过门禁。
- Grok 修复复审发现文本后缀核验的真实漏洞：旧的“你好”可包含新的“好”，重复
  尾句也不能证明本次写入。改用已有 `id` 请求关联及 `meeting_id` 数据归属，
  等待实际写入、读回与结束回执；提供显式“保存转写”恢复失败写入。
  同时亲证其他主张：effect 表达式会返回注销函数；服务端重复 end 仍返回 ended；
  窄屏 CSS 已设行换行，新增对所有行操作的浏览器命中测试。有效缺陷与误判分开处理。

## 用户视角与能力完整性

最终 Grok 4.6：APPROVE_WITH_NITS；DeepSeek V4 Pro：APPROVE。Grok 一次 CLI
调用仅返回阅读计划并达到轮次上限，未计为通过；重新限制工具后的完整报告才用于闸门。
最终非阻断观察逐项处置：

- 替换/读回未重复校验全文：接受现有服务端写盘后相关回执契约；真实 route/store
  测试钉住此契约，不把假想“服务端回显成功但不写盘”当已发现缺陷。
- fieldset 的 display:contents 兼容性：评审明确为未复现假设；保留现有禁用及
  requestClose 合并调用保护，真实跨平台可用性继续实机验收。
- 保存失败后取消排队导航：这是保留草稿的既定行为；重试设置/切换路径已实测。
- 纪要先放入输入框再尝试收起：接受用户显式发送到草稿的行为，会议失败仍保留，
  未丢数据也未自动发送给模型。
- 强制杀标签页不能等待最终回执：不在本批保证范围；用户关闭/导航路径已覆盖。

本轮验证了 320、390、760、1440 宽下的对话管理，及现有工作区/设置回归。
保留新建、人工标签、手动分组、AI 分组、AI 提取、规则整理、图谱、相关对话、
知识提炼、摘要导出、回收站、恢复和永久删除。减少的是重复全选按钮与装饰。
技能导入/目录/URL、知识库、MCP、应用、场景与专家、会议、任务板仍可访问。
安全确认与停止仍优先可达，未以视觉清理为理由关闭任何能力。

审美上采用已有中性色和连接图标，强化文字识别与层级；没有宣称完成全产品
重新设计。更大的体验问题仍在 #481/#476：完整资源管理空间偏小；代码接力
发现主要依赖 /code 和消息操作；“项目”实体与原生完整工作台尚未交付。
这些应在独立验收下继续，不能用隐藏复杂功能来制造简洁。

## 验证边界

协议 fixture 来自真实 handleMessage + 临时 ThreadManager 输出，测试覆盖 ACK
与持久化回执、错 ID/模式/目标分区、超时、离线、取消、部分成功、旧版能力探测。
实际 App 与会议 UI 使用独立 Chrome headless、合成传输及合成 PCM；不会访问真实
会话、麦克风、用户 Chrome 或配置。会议测试证明关闭时序，不证明实机识别性能；
本机没有 Windows 主机，Windows 实机仍需后续验证。

## 回归 case

1. 动作：在标签过滤/运行状态改变后操作全选、删除，或录制尾段点击收起。
2. 失败：删除对象扩大、发送拒绝却显示成功、列表高度归零、未识别末段被销毁。
3. 归责：实现与原有测试覆盖不足；外部模型亦有未亲证的触发路径和归因错误。
4. 保护：操作目标属于用户选择、成功来自持久化回执、短屏能力可达、关闭不丢末段。
