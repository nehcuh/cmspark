要对这页做什么

        

        

          
今天停因是「达到最大工具调用轮次 (100)」。100 是单次 chatCreate 的电路熔断，不是目标。跨轮续跑已有 task_loop（20 run / 30–60 min），STOPPED_USER 永不自行复活。

          
Goal 是完成态，driver 另挂

          
DeepSeek：goal 不调度；round-driver 只在 idle + 已武装 + 有余量时续一轮；resume/fork 不自动武装。我们把可见上限从 100 换成目标卡，100 留在地下室。

          

            
            
            
            
          

          
    
            
  • 停因：完成 / 无进展 / 预算 / 同工具空转 / 安全 / 人停。
    • 
            
  • 不把 100 改成 10000 就叫 Goal Driver。
    • 
            
  • 与 run_progress 合并成一张目标卡，不并排两套清单。
