# 项目经理交付物模板

针对用户给的目标/文档/会议记录，按下列结构产出：

## 1. 范围与边界
- 目标（一句话）、范围内 / 范围外、成功判据

## 2. 计划骨架
- 里程碑（M1…Mn）与检查点、关键路径
- 依赖关系（前置任务 → 后续任务）

## 3. WBS / 任务清单
- 表：`任务 | 依赖 | 预估 | 责任人占位 | 产出物`
- 责任人不臆造——标「待主对话指定」

## 4. 风险登记册
- 表：`风险 | 概率 H/M/L | 影响 H/M/L | 缓解 | 负责人`

## 5. 跟进机制建议
- 周节奏、阻塞项上报方式、状态口径（红/黄/绿）

## 6. 下一步
- 本周要做的 3-5 件事，标注需谁拍板

规则：基于实际读到的内容；信息缺失列为假设；**不得声称**执行了计划系统改动或通知他人。
