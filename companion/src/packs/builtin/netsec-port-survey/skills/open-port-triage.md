# 开放端口分诊

拿到 `netsec_port_scan` 结果后：

## 分诊维度

| 维度 | 问题 |
|------|------|
| 预期性 | 该端口是否应在此环境开放？ |
| 暴露面 | 是否仅内网 / 是否可能被外网路由到？ |
| 服务假设 | 常见端口对应服务（须标注**假设**，非 banner 实测则勿写死） |
| 优先级 | 未鉴权管理口、数据库、远程桌面 > 业务 API > 纯探测响应 |

## 输出注意

- 区分 **tool 实测** vs **常识推断**。
- 建议可执行：关端口 / 绑监听 / ACL / 补丁 / 换非标端口仅作纵深而非主措施。
- 无开放端口：写明「在授权范围内未发现开放端口」，并提示范围是否过窄。
