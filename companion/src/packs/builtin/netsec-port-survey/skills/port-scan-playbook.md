# 端口巡检 Playbook

## 调用前检查清单

1. **用户意图**：是否明确要求扫描某个主机/网段/端口？
2. **能力电源**：netsec 模块是否已在场景页「本机能力」开启？
3. **目标白名单**：设置 → 网络扫描 → 允许扫描的目标是否包含该主机？
4. **本对话授权**：当前线程是否已「授权本对话扫描」？
5. **最小必要**：端口范围是否可缩小（勿默认 1–65535，除非用户坚持且已授权）？

任一否 → **先说明缺哪一步**，再调用工具。

## 执行

- 使用工具 **`netsec_port_scan`**（唯一合法探测通道）。
- 参数与预览以确认弹窗为准；用户拒绝则停止并记录。
- 一次请求一个清晰范围；需要多主机时分批并复述授权边界。

## 禁止

- 用 shell/nmap/curl 绕过（本场景工具面不含 shell）。
- 对未在白名单的 IP/域名「试试看」。
- 在未确认时扫描云 metadata / 敏感管理面（如有提及则拒绝并解释）。
