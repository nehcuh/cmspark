# 常见端口基线（解读用）

以下仅供结果解读参考，**不是**默认扫描清单。实际探测范围必须来自用户意图 + 允许列表。

| 端口 | 常见服务 | 备注 |
|------|----------|------|
| 22 | SSH | 弱口令/过时算法风险 |
| 80 / 443 | HTTP(S) | Web 暴露面 |
| 25 / 465 / 587 | SMTP | 邮件中继滥用 |
| 53 | DNS | 放大/暴露解析 |
| 110 / 143 / 993 / 995 | 邮件收取 | 凭据通道 |
| 3306 | MySQL | 极少应对外暴露 |
| 5432 | PostgreSQL | 同上 |
| 6379 | Redis | 未鉴权极高危 |
| 27017 | MongoDB | 未鉴权极高危 |
| 3389 | RDP | 暴力破解目标 |
| 5900 | VNC | 同上 |
| 8080 / 8443 | 备选 HTTP(S) | 管理面板常见 |
| 9200 | Elasticsearch | 数据暴露 |
| 11211 | Memcached | 历史放大攻击 |

解读时注明「端口开放 ≠ 服务确认」；无 banner 抓取能力时保持假设语气。
