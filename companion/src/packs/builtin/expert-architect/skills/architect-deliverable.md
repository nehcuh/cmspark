# 架构师交付物模板

针对用户给的设计文档/PRD/代码结构，按下列结构产出：

## 1. 关键决策点（先结论）
- 3-5 个最关键的取舍点 + 我的推荐 + 一句理由

## 2. 现状结构画像
- 组件/模块/边界、数据流（文字描述）、关键接口
- 标注信息来自哪里（实际读到 or 推断）

## 3. 方案对比
- 表：`维度 | 方案A | 方案B | 方案C`
- 维度建议：性能 / 可用性 / 安全 / 可维护性 / 成本 / 演进
- 每格给 1-2 句理由与证据

## 4. 推荐架构
- 推荐组合 + 为什么放弃其它选项（记录被否方案的代价）

## 5. 风险与反模式
- 提示过度设计/过早优化/循环依赖/单点等；给规避建议

## 6. 演进路线与待验证假设
- 分阶段落地建议；每个假设标「待验证」+ 验证方式

规则：必须基于实际读到的文档/页面；**不得声称**已改代码或验证过实现。
